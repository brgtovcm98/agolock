# ADR-010: Item 생성과 마스터 수정 권한

- 상태: 승인됨
- 날짜: 2026-10-20

## 맥락

공유 사용자의 `MANAGE` 권한은 재고 추가를 허용합니다. 기존 문서는 공유 사용자가 새 Item까지 만들 수 있다고 했지만, 마스터 공통 필드와 Item 대표 사진 수정은 소유자만 가능합니다. 이 조합에서는 공유 사용자가 만든 마스터를 생성자가 수정할 수 없어 데이터 품질 문제가 생깁니다. 또한 공유 사용자는 Category를 새로 만들 수 없습니다.

## 결정

- 1차에서 새 Item 마스터 생성은 Space 소유자만 수행합니다.
- 공유 사용자의 `MANAGE`는 접근 가능한 기존 Item에 Inventory를 추가하는 것까지 허용합니다.
- 공유 사용자는 접근 가능한 Item을 선택할 수 있지만 새 Item을 만들 수 없습니다.
- Item 마스터 공통 필드와 Item 대표 사진 수정은 `OWNER`만 가능합니다.
- Inventory 오버라이드, Inventory 사진, 상태 수정은 `EDIT` 이상이 수행합니다.
- Category 생성·수정·삭제·병합은 소유자만 가능하며, 공유 사용자는 기존 Category만 선택합니다.

## 결과

- 공유 사용자가 수정할 수 없는 마스터를 만드는 문제를 막습니다.
- 공유 `MANAGE`의 의미가 "기존 Item에 재고 추가"로 명확해집니다.
- 공유 사용자가 새 물건을 등록해야 할 때는 소유자에게 요청하는 흐름이 필요합니다.
- 3차에서 그룹 공유나 위임 편집을 도입할 때 이 결정을 다시 검토합니다.

## 대안

- 공유 사용자에게 신규 Item 생성과 제한적 마스터 수정을 함께 허용: 생성자와 소유자 권한이 겹쳐 규칙이 복잡해집니다.
- 공유 사용자가 만든 Item의 마스터를 생성자가 계속 수정: 다른 Inventory에 미치는 영향과 소유권 경계가 불명확해집니다.
- 승인 워크플로 도입: 1차 범위를 넘습니다.
