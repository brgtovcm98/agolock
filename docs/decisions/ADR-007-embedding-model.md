# ADR-007: Gemini 멀티모달 임베딩

- 상태: 승인됨
- 날짜: 2026-10-19

## 맥락

이미지 기반 유사도 검색이 핵심 요구입니다. OpenAI 임베딩 API는 텍스트 전용이므로 이미지 임베딩에 직접 사용할 수 없습니다. 이미지와 텍스트를 함께 다룰 수 있는 모델이 필요합니다.

## 결정

- 이미지 임베딩은 Gemini 멀티모달 임베딩을 사용합니다.
- MVP는 이미지 임베딩만 사용하고 키워드 검색은 PostgreSQL로 처리합니다.
- `item.embedding`과 `inventory.effective_embedding`을 저장합니다.
- 재고 대표 사진이 있으면 재고 벡터를, 없으면 마스터 벡터를 사용합니다.
- 임베딩 모델, 차원, 버전을 함께 저장합니다.
- 모델 변경 시 재임베딩 job을 실행합니다.
- pgvector HNSW cosine 인덱스를 사용합니다.
- 최종 모델과 차원은 샘플 벤치마크 후 고정합니다.

## 결과

- 이미지 검색과 텍스트 검색을 같은 벡터 공간으로 확장할 수 있습니다.
- 모델 변경 비용이 크므로 버전 관리가 필수입니다.
- 외부 provider 비용과 지연을 관측해야 합니다.
- 이미지가 없는 재고는 마스터 벡터를 상속합니다.

## 대안

- 자체 호스팅 CLIP/SigLIP: 비용은 낮출 수 있지만 운영 부담이 큽니다.
- OpenAI 텍스트 임베딩: 이미지 검색에 사용할 수 없습니다.
- 이미지와 텍스트를 별도 공간에 임베딩: 구현은 단순하지만 cross-modal 검색이 어렵습니다.
