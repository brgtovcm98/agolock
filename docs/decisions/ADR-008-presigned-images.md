# ADR-008: Presigned URL 기반 이미지 접근

- 상태: 승인됨
- 날짜: 2026-10-19

## 맥락

이미지는 개인정보와 연관될 수 있고, 모바일 업로드와 다운로드가 빈번합니다. 애플리케이션 서버가 모든 이미지 바이트를 중계하면 대역폭과 메모리 부담이 커집니다. 동시에 권한 확인과 원본 보호가 필요합니다.

## 결정

- S3 호환 객체 스토리지를 사용합니다.
- 버킷은 비공개로 유지합니다.
- 업로드와 다운로드에 짧은 TTL의 presigned URL을 사용합니다.
- 서버는 presigned URL 발급 전에 권한을 확인합니다.
- 업로드 완료 후 서버가 객체를 검증하고 재인코딩합니다.
- EXIF를 제거하고 썸네일을 생성합니다.
- presigned URL은 로그에 남기지 않습니다.
- 즉시 회수가 필요하면 앱 프록시 또는 CloudFront signed URL을 사용합니다.

## 결과

- 서버 대역폭과 메모리 사용이 줄어듭니다.
- 모바일·대용량 업로드가 안정적입니다.
- URL은 TTL 동안 bearer 자격증명처럼 동작합니다.
- 업로드 후 검증과 후처리 파이프라인이 필요합니다.

## 대안

- DB bytea: 소규모에는 단순하지만 백업·확장·CDN에 불리합니다.
- 앱 서버 프록시: 즉시 회수는 쉽지만 대역폭 부담이 큽니다.
- 공개 버킷: 개인정보 보호 요구에 맞지 않습니다.
