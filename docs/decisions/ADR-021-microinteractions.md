# ADR-021: 레이아웃 일관성과 마이크로인터랙션

- 상태: 승인됨
- 날짜: 2026-10-23

## 맥락

P0·P1에서 화면이 늘어나면서 버튼·입력·필터의 높이와 페이지 간격이 갈라졌습니다. 버튼은 이동량과 그림자 변화가 어긋나 눌림이 즉시 튀었고, 재고·편집·공유·카테고리 변경에는 성공 확인이 없었습니다. 네오브루탈리즘의 하드 섀도는 높이를 나타내므로, 모션은 장식이 아니라 그림자 물리를 완성하는 방향이어야 합니다.

## 결정

- 컨트롤 높이를 44/48/56px, 페이지 루트 간격을 24px, 카드 본문 패딩을 16px로 고정합니다.
- 편집·설정 폼은 데스크톱에서 `max-w-2xl`로 제한하고, 검색 필터는 44px 컨트롤 툴바로 묶습니다.
- FAB는 홈·공간·재고 목록에만 표시합니다.
- CSS 모션 토큰(`--motion-*`, `--ease-*`)을 사용하고, 버튼은 `hover -1px/+5px`, `active +2px/+2px`로 그림자 바깥 모서리를 고정합니다.
- 포커스 링은 전경색 3px + offset 3px로 통일합니다.
- 토스트는 `@radix-ui/react-toast`로 구현하고, 성공·정보 5초, 오류 8초, 모바일 1개·데스크톱 3개, FAB 위/우하단 배치를 사용합니다.
- `prefers-reduced-motion`에서는 이동·스케일·토스트 애니메이션을 제거합니다.
- 성공 피드백은 가능한 한 인라인을 유지하고, 화면 이동이나 목록 갱신이 있는 동작에만 토스트를 사용합니다.

## 결과

- 모든 화면의 컨트롤 높이와 간격이 일관되고, 44px 터치 타깃을 확보했습니다.
- 버튼·카드·대화상자·토스트의 모션이 같은 물리 규칙을 공유합니다.
- `@radix-ui/react-toast` 의존성과 약 11KB가 추가됩니다.
- 토스트는 폼 검증 오류를 대체하지 않으며, 오류는 인라인을 기본으로 합니다.
- 토스트 퇴장은 현재 등장만 적용됩니다. 필요하면 Radix Presence 조합을 추가합니다.

## 대안

- Sonner: 도입은 빠르지만 스타일 오버라이드와 focus 일시정지 검증이 추가로 필요합니다.
- 직접 구현: 타이머·큐·포커스·스크린리더 엣지 케이스 비용이 큽니다.
- 토스트 상단 배치: sticky 헤더와 경쟁하고 모바일에서 닫기 도달성이 떨어집니다.
- `framer-motion`: 이 범위의 모션은 CSS와 Radix `data-state`로 충분합니다.
